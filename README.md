# Как установить Hostkeep

Hostkeep — SSH-клиент. Серверы, ключи и заметки хранятся зашифрованными на каждом
устройстве и синхронизируются через ваш Google Диск. После переустановки системы
достаточно поставить Hostkeep и войти в Google.

Сайт: <https://rozsario.github.io/hostkeep-site/>. Файлы — на странице последнего выпуска:
<https://github.com/Rozsario/hostkeep-releases/releases/latest>

## Windows 10 и 11

1. Скачайте `Hostkeep-Setup-<версия>.exe`.
2. Запустите его. Права администратора не нужны: программа ставится только для вас, в
   `%LOCALAPPDATA%\Programs\Hostkeep`.
3. Windows может предупредить: «Система Windows защитила ваш компьютер». У установщика нет
   платной подписи, поэтому SmartScreen его не знает. Нажмите «Подробнее», затем «Выполнить в
   любом случае». Это нужно только при первой установке: обновления приложение ставит само.

Без установки: `Hostkeep-<версия>-portable.zip` — распакуйте и запустите `hostkeep.exe`. Такая
копия сама не обновляется, о новой версии она сообщит и откроет эту страницу.

Удаление — «Параметры → Приложения → Hostkeep → Удалить». Данные (`%APPDATA%\Hostkeep`)
остаются на месте.

## Android 14 и новее

1. На телефоне откройте страницу выпуска и скачайте `Hostkeep-<версия>-arm64.apk`.
2. Откройте скачанный файл. Android спросит, можно ли браузеру устанавливать приложения, —
   разрешите (только для этого раза, потом разрешение можно снять).
3. Нажмите «Установить».

Дальше обновления приходят изнутри приложения: баннер «Доступна версия …» → «Обновить». В
первый раз Android попросит разрешить Hostkeep устанавливать обновления.

## Первый запуск

1. Нажмите «Войти через Google» и выберите свой аккаунт. Если хранилище в нём уже есть
   (с другого устройства или до переустановки), всё вернётся само.
2. Создайте ключ восстановления и сохраните его вне компьютера: распечатайте или запишите.
   Он откроет хранилище, даже если доступ к Google-аккаунту потерян.
